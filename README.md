# 贵金属报价趋势监测（金 / 银 / 铜）

- 市场：国内 / 香港 / 伦敦；粒度：年 / 月 / 日 / 时；金与银支持切换 **元/克**
- 最新价为真实现货（gold-api.com），汇率取 Frankfurter / open.er-api
- GitHub Actions 每 15 分钟例行重建历史曲线与重大事件
- 页面打开时由浏览器直连现货源补齐最新价（静态托管模式下同样实时）
- 页面每 5 分钟自动检查数据新版本并局部更新（无需手动刷新）

## 消息推送（微信域内，可选配置）

在仓库 **Settings → Secrets and variables → Actions** 中添加：

| Secret | 用途 | 获取方式 |
| --- | --- | --- |
| `WECOM_WEBHOOK` | 企业微信群机器人 Webhook（主通道，免费无限量） | 企业微信 → 群设置 → 群机器人 → 添加 → 复制 Webhook 地址 |
| `SERVERCHAN_SENDKEY` | Server酱 SendKey（备选，免费 5 条/天） | sct.ftqq.com 微信扫码登录后获取 |

两个都不配也能正常运行（推送内容仅在 Actions 日志留痕，不影响数据管线）。

- **异常告警**：价格/事件停更、校验未过、事件源全停时推送（首次立即发，持续异常 3 小时一条汇总）
- **数据简报**：每天 8/10/12/14/16/18 点各推送一次金银铜最新价与最新事件

本地运行：`node generate.js`（生成 data/*.json）
